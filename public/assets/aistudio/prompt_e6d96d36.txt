# MASTER PROMPT — GLINTS AI JOB ASSISTANT

## 1. Project Overview

Build a standalone, locally hosted web application named **Glints AI Job Assistant**.

The application will help automate the job-search and application preparation process for a cybersecurity professional seeking employment in Jakarta, Indonesia.

The system must integrate OpenAI for AI-powered job analysis, CV matching, suitability scoring, and customized cover-letter generation.

The application must operate in **Approval Mode**: every application must be reviewed and explicitly approved by the user before submission.

This must be a functional software project, not a prototype or static dashboard.

## 2. User Profile and Job Search Configuration

Use the following default job-search criteria:

- Location: Jakarta, Indonesia.
- Work arrangements: On-site, Hybrid, and Remote Jakarta-based.
- Minimum expected salary: IDR 8,000,000 per month.
- Salary filtering: Include negotiable and undisclosed salaries when the vacancy is relevant.
- Experience: Junior–Mid Level and Mid Level.

### Target Job Positions

Prioritize the following positions:

1. Cybersecurity Engineer
2. IT Security Engineer
3. Network Security Engineer
4. Security Analyst
5. IT GRC Specialist
6. Solution Consultant
7. Security Presales Engineer

### Professional Background

Use the following profile as the initial AI job-matching reference:

- More than three years of cybersecurity and network security experience.
- Experience with Fortinet and Palo Alto Networks firewalls.
- Network security implementation and troubleshooting.
- VPN, NAT, IDS/IPS, and NGFW.
- SIEM and security monitoring.
- Wazuh, ELK, OpenSearch, and Suricata.
- Security implementation, technical presales, and solution consulting.
- ISO 27001 and NIST familiarity.
- Low-Level Design (LLD), User Acceptance Testing (UAT), and technical documentation.

Allow the user to upload and manage their latest CV. The uploaded CV must become the primary source for AI matching rather than relying exclusively on this initial profile.

## 3. Technical Architecture

Build the application using:

| Component | Technology |
|---|---|
| Frontend | React + Vite |

| API Framework | Express.js |
| Database | SQLite |
| AI Provider | OpenAI API |
| Browser Automation | Playwright, restricted to permitted workflows |

| Operating System | Ubuntu 26.04 LTS |
| Application Port | 3080 |

The application must be standalone and run locally on the user's sifulbahri Ubuntu machine.

Do not use Docker.

Do not use pnpm.

Use npm for all package management.

## 5. Core Features

### Module 1 — Dashboard

Create a professional dashboard showing:

- Total discovered jobs.
- Jobs awaiting analysis.
- Jobs matching the user's profile.
- Applications awaiting approval.
- Applications submitted.
- Interviews.
- Rejections.
- Application success rate.

Include visual charts for application activity and job-match distribution.

### Module 2 — Job Discovery

Allow the user to:

- Import a Glints vacancy URL.
- Paste a job description manually.
- Add company information.
- Add position title.
- Add salary information.
- Specify employment type.
- Specify location.
- Record the original vacancy URL.

Support permitted integrations and data sources.

IMPORTANT COMPLIANCE REQUIREMENTS:

- Do not scrape Glints without prior authorization.
- Do not bypass CAPTCHA, authentication, anti-bot protection, or access restrictions.
- Do not automatically submit applications through unauthorized browser automation.
- Do not violate Glints' Terms of Use.
- Use manually imported vacancy information or officially authorized integrations.
- Playwright may be used for permitted local browser workflows and navigation initiated or approved by the user.

### Module 3 — AI Job Analyzer

Integrate the OpenAI API.

For each vacancy, analyze:

- Technical skill compatibility.
- Work experience compatibility.
- Education requirements.
- Required certifications.
- Seniority compatibility.
- Location compatibility.
- Salary compatibility.
- Job responsibilities.
- Potential skill gaps.

Generate a suitability score from 0 to 100.

Use these initial classifications:

- 85–100: Excellent Match.
- 70–84: Good Match.
- 50–69: Moderate Match.
- Below 50: Low Match.

Provide explanations for every score.

Never invent qualifications, employment history, certifications, or experience.

### Module 4 — CV Management

Allow the user to:

- Upload PDF and DOCX CV files.
- Extract CV text.
- Preview extracted information.
- Manage multiple CV versions.
- Select a preferred CV.
- Generate recommendations for CV improvements.

Preserve factual accuracy.

Never fabricate experience or technical skills.

### Module 5 — AI Cover Letter Generator

Generate customized cover letters based on:

- User's CV.
- Job description.
- Company information.
- Position title.
- Relevant technical experience.

Allow editing, regeneration, copying, and saving.

### Module 6 — Application Approval Queue

This module is mandatory.

Every prepared application must enter an approval queue.

Display:

- Company name.
- Job title.
- Salary information.
- Location.
- AI suitability score.
- Selected CV.
- Generated cover letter.
- Original vacancy URL.

Provide the following actions:

1. Review Application.
2. Edit Cover Letter.
3. Change CV.
4. Approve Application.
5. Reject Application.
6. Open Original Vacancy.

The approval process must be explicit and recorded.

Approval does not bypass the website's own application requirements or authorization restrictions.

For Glints, the user should complete the final submission through an authorized application workflow unless an officially permitted integration supports submission.

### Module 7 — Application Tracking

Maintain application records with these statuses:

- DISCOVERED
- ANALYZED
- PREPARED
- PENDING_APPROVAL
- APPROVED
- SUBMITTED
- INTERVIEW
- REJECTED
- WITHDRAWN

Record:

- Company.
- Job title.
- Original vacancy URL.
- Salary.
- Match score.
- Application date.
- Submission date.
- Application status.
- Notes.
- Follow-up date.

Prevent duplicate applications to the same vacancy.

### Module 8 — Settings

Provide configurable settings for:

- OpenAI API key.
- OpenAI model.
- Minimum salary.
- Target locations.
- Target job positions.
- Work arrangements.
- Minimum AI match score.
- Preferred CV.
- Application approval mode.

Store secrets only on the backend.

Never expose API keys to frontend JavaScript.
